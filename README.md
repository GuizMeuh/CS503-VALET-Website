# VALET — Project Webpage

This repository hosts the project webpage for **VALET: VLM-Assisted LEarning with Targeted queries**, a CS-503 Visual Intelligence course project at EPFL.

**Live site:** https://guizmeuh.github.io/CS503-VALET-Website/

## Structure

- `index.html` — main webpage
- `static/` — images, GIFs, and other assets
- `interactivity/` — source code for the interactive "Be the Oracle" demo. This is the template for the [HuggingFace Space](https://huggingface.co/spaces/GuizMeuh/VALET-betheoracle) we host.
