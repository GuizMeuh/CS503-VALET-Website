Interactive demo for **VALET** (VLM-Assisted LEarning with Targeted queries).
A PPO agent trained on MiniGrid-DoorKey-16×16 can call a human oracle when uncertain.
When it queries, *you* choose the action — exactly replacing the BFS oracle from training.
